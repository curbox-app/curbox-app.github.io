Feature · Browser extension

A website blocker extension for Chrome and Firefox.

Curbox for the browser is a free, open source website blocker extension. It blocks whole sites or just the addictive part, like YouTube Shorts on desktop, sets daily limits and schedules, runs focus sessions, and keeps every number on your own computer.

Block YouTube Shorts on desktop, keep YouTube

Most website blockers think in whole domains: block youtube.com and you lose tutorials, music and lectures along with Shorts. Curbox blocks by URL pattern, so you can take out one section of a site and leave the rest. These are the patterns the extension understands, the same ones as the Android app:

youtube.comThe whole site
youtube.com/shortsOne section of a site
/reelsThat path on any site
*.reddit.comThe site and its subdomains
youtubeAny site with that word in its domain
r:shorts|reelsA raw regular expression, for advanced rules

For Shorts specifically, add youtube.com/shorts to a group. If you also want Shorts gone from YouTube's home page and sidebars, turn on the UI Hider rule for Shorts. The website blocking guide has an in-page tester for these patterns.

What the extension does

Block

Website groupsPut sites in groups with active hours: all day, one daily schedule, or different times for each weekday, including ranges past midnight.

Daily limitsOnly browsing inside the active hours counts. A zero-minute limit blocks the site for the whole window.

On each openCurbox stops you once when you enter a group, then asks again after you leave and come back.

Lists and packsImport a word list or a hosts file, or add a community website pack.

Reduce

UI HiderOn YouTube, hide the home feed, recommendations, comments, Shorts, live chat or the notification count. On X, hide For you and open Following.

Site grayscaleTurn chosen sites gray on a schedule while everything else stays in colour.

Gentle PromptsA small live note over chosen sites, such as your time on this site today.

Sip & Stretch and Urge SurfingShort movement breaks, and a calm way to ride out a craving instead of unlocking.

Focus & see

Focus ModeBlock selected sites, or everything except them, for a set time. Choose whether you may quit early.

Pomodoro2 to 12 rounds with breaks up to 120 minutes. Sites unblock during breaks.

Honest usage statsToday's total, a weekly graph, a four-week view, and a breakdown inside each site, so youtube.com splits into videos and Shorts.

CSV exportDaily breakdown, totals, or both, in the same layout as the Android export.

What happens when you hit a block

The warning screen offers the same choices as the Android app. Never Unlock is a total lockdown. Require effort means typing a sentence exactly (pasting is disabled), stating your intent, or solving adaptive math where a wrong answer costs a 15-second wait. Wait to unlock gives you a fixed amount of time, or asks how much you need. On top of any of these you can add a countdown before Proceed, a cap such as "2 of 3 opens left", a daily focus requirement, and your own message. Videos and music behind the warning screen pause and cannot restart until you are through.

The full list of unlock options is in the unlock challenges guide.

Why it asks for each permission

A website blocker has to see which site you are on, so it needs real access. Here is every permission and what it is used for, taken from the project's README.

CURBOX · PERMISSIONS

storage, unlimitedStorageKeep usage, settings and imported lists on your device
tabsKnow which site is active, so only time you spend counts
alarmsSave usage and end focus sessions and unlocks on time
idlePause the clock when you step away or lock the screen
faviconShow site icons in your usage list
scriptingShow the warning screen on tabs open before install
all sitesWarning screen, prompts, grayscale and UI hiding on sites you choose
NO ACCOUNT · NO ADS · NO ANALYTICS

Usage is stored a day at a time in your browser and kept for four weeks. It never sends your data to the developer. It only connects out to download a website pack you choose, to show the Terms and privacy policy on first run, and for Sync if you turn it on. Sync is optional: pair with Curbox Sync on your Android phone using a code it shows, and focus mode, website groups and usage are shared over WiFi or Tailscale, encrypted, without passing through a Curbox server. The privacy policy has the details.

Website blocker extension FAQ

Is there a free website blocker extension for Chrome and Firefox?
Yes. Curbox is free and open source, with no account, no ads and no analytics. Install it from the Chrome Web Store for Chrome, Brave, Edge, Helium and other Chromium browsers, or from Firefox Add-ons for Firefox.
How do I block YouTube Shorts on desktop?
Add youtube.com/shorts to a Curbox website group. That blocks only the Shorts pages, so normal videos, search and subscriptions keep working. You can also turn on the UI Hider rule that hides Shorts from YouTube's pages.
Does the extension track my browsing?
It records time per site so it can show you your usage, but that data stays in your browser's local extension storage. Usage is kept for four weeks, then cleared automatically. There is no Curbox server it reports to.
Does time count for tabs left open in the background?
No. Time only counts while the tab is active, the window is focused, the page is visible and you are at your computer.
Does it work on Firefox for Android?
The project says the Firefox build is made to run on Firefox for Android too, where the app opens as a tab. On Android, the Curbox app also blocks websites in many browsers on its own.
Can it sync with my phone?
Yes, optionally. Sync pairs the extension with Curbox Sync on your Android phone using a code from the phone. Focus mode, website groups and usage are shared over WiFi or Tailscale, encrypted, with no Curbox server in between.
