How the mindful message app feature works

In Curbox this feature is called Mindful Messages, and it lives under Gentle Prompts in the Reducers tab. It is a nudge, not a block. The app opens as usual, and your message sits on top of it for the whole time you use it, so the question you wrote for yourself stays in view instead of flashing past.

  1. Install Curbox from the downloads page and finish onboarding.
  2. Open Reducers → Gentle Prompts and switch on Enable Mindful Messages.
  3. Tap Select Apps and choose the apps that should show the reminder.
  4. Write your messages in the MESSAGES area, one per line. Each line shows as its own message.
  5. Insert placeholders where you want live numbers, then set the text size, text opacity and background color.

A dark background with large text tends to be the most noticeable without feeling harsh. Full details are in the Mindful Messages docs.

The four live placeholders

Placeholders are what make a reminder hard to scroll past. A fixed "Put the phone down" stops working after a few days. A number that changes every time keeps telling you something new.

{app_usage_today}Time spent in this app today.
{screentime_today}Total screen time across all apps today.
{live_session_duration}How long you have been in this app continuously, right now.
{reel_count}How many short-form videos you have watched today. See the reels counter.

When a reminder helps, and when it does not

Most of the time you open a distracting app, you did not decide to. Your thumb did. A reminder works by putting a second of thinking back into that moment, which is often all it takes to close the app again. It is the gentlest tool Curbox has, and for many people it is the right first one, because nothing is taken away.

It works best when the message is yours. "Is this really important?" written in your own words reads like a note from a friend. The same line copied from somewhere else turns into wallpaper within a week. Changing the wording now and then, or using several lines, keeps it fresh.

It works less well on a bad day, when you have already decided to scroll and nothing will talk you out of it. That is not a failure of willpower; it just means you need something with more friction. Curbox lets you add that later without starting over: a daily limit in App Pause, a count limit on Reels, or a break that actually happens. Start with the reminder, see how far it gets you, and only then add more.

Two places a reminder can appear

Curbox has two kinds of message, and they suit different moments.

Inside the app: Mindful Messages

The app opens and stays usable. Your message overlays it the whole time. Good for apps you want to keep, like YouTube for tutorials, but use more mindfully.

Before the app: the warning screen

When an App Pause or short-form limit kicks in, the pause screen can show a Custom Message, or a random one from your list each time. Pair it with the vibrating delay timer and you get a few seconds to actually read it before deciding.

If a reminder on its own is not enough, the warning screen can also ask for effort before you continue, such as typing a sentence or stating your intent. See unlock challenges.

Questions about app reminders

How do I get a reminder when I open an app on Android?

Install Curbox, then go to Reducers, open Gentle Prompts, turn on Enable Mindful Messages, choose the apps, and write your message.

Can the reminder show how long I've been on the app?

Yes. Use the {live_session_duration} placeholder for the current session, or {app_usage_today} for the total in that app today. Both update live each time the message appears.

Does a mindful message block the app?

No. Mindful Messages is a nudge: the app stays usable with your message on top. To block an app after a limit, use App Pause, which can show its own custom message on the pause screen.

Can I have more than one message?

Yes. Write one message per line and each line shows separately. The warning screen can also pick a random message from your list.

Can I change how the message looks?

Yes. You can set the text size, text opacity and background color so the message is noticeable without covering what you need to see.
