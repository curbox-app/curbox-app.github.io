Open-source app blockers for Android.

Seven blockers whose code you can actually read, what each one is good at, and how to check that "open source" on a listing is the real thing.

Listings checked November 2026

An app blocker is a strange thing to trust blindly. To stop you opening Instagram, it has to see that Instagram is on screen, and on Android that means the Accessibility Service: a permission that can read the text on your display and watch what you type. Every blocker needs it. Most of them are closed source, so you cannot see what they do with it.

Open-source blockers flip that. The code is public, the license lets anyone rebuild it, and on F-Droid the app you install is built from that same code. We make one of the apps below, so read our entry with that in mind. We have tried to describe the others fairly, using their own listings.

Five field tests: is it really open source?

"Open source" is a phrase anyone can put in a store description. These checks take a few minutes and tell you whether there is substance behind it.

Find the repository

The listing or website should link to the code on GitHub, GitLab or Codeberg. Open it. Is it the whole app, with recent commits, or a nearly empty repo with a README? A real project has history: issues, pull requests, releases.

Read the license file

Look for a LICENSE file in the repository root. GPL, MIT, Apache and similar licenses let you read, build and share the code. "Source available" or a custom license that forbids modification is not the same thing, and extra conditions are worth reading.

Check for an F-Droid build

F-Droid compiles each app on its own servers from the published source and only accepts free-software dependencies, so ad and tracking SDKs cannot be quietly included. Tracking and other concerns are labelled as Anti-Features on the app page. IzzyOnDroid distributes the developer's own builds after scanning them, which is useful but a step less direct.

Look for reproducible builds

Some F-Droid apps are reproducible: F-Droid's own build matches the developer's signed build byte for byte, which proves the published app came from the published code. When an app page says it is signed by the developer and verified by F-Droid, that is what it means. Not every app does this yet.

Match the versions

Compare the version number in the app's settings with the latest tag in the repository. If the store has a version the repository has never heard of, or the repository has not been touched in years while the app keeps updating, the code you can read is not the code you are running.

What open source does and does not promise

It does give you

  • The ability for anyone to check what the app does with Accessibility access.
  • A public record of every change, so a bad update is visible.
  • The right to fork it if the developer disappears or goes in a direction you dislike.
  • On F-Droid, a build made from that exact code.

It does not guarantee

  • That anyone has actually audited it. Public code helps only if people read it.
  • That it works well, or keeps working after Android or Instagram update.
  • That it never uses the internet. Check the permission list separately.
  • That a download from a random APK site is the same app. Use official sources.

The combination that matters most is open source plus no internet permission plus an official install source. Code you can read tells you what the app should do; no network access means that even if something were wrong, the data has nowhere to go. Questions

What is the best open-source app blocker for Android?

It depends on what you need. Curbox covers the most ground (apps, websites, Reels and Shorts, unlock challenges). DetoxDroid is strong on grayscale and doomscroll breaks. TimeLimit is built for parents managing a child's phone. FocusFeed is a simple Pomodoro blocker. The directory on this page explains each.

Are open-source app blockers safe?

Open source makes an app checkable, not automatically safe. The biggest gain is that anyone can read what the app does with its Accessibility access. Pair that with no internet permission and an official install source, and you have about the strongest guarantee you can get.

Is Curbox open source?

Yes. The complete source is on GitHub under the GNU GPL v3, and F-Droid builds it from that source. The Android app also has no internet permission in any variant.

What is the difference between F-Droid and IzzyOnDroid?

F-Droid builds each app itself from the published source code and only accepts free-software dependencies. IzzyOnDroid is a separate repository that distributes the developer's own builds after scanning them. Both only list open-source apps.

Does open source mean the app is free?

Almost always free to download, but not always free of charge for every feature. TimeLimit, for example, charges for some features that use its hosted server, while self-hosting stays free.
