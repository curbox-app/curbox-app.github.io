The same trade every time

Whichever app you leave, the changes look much the same. Here they are in one place so the individual pages can get on with the details.

What you gain

  • Block part of an app, such as Reels or Shorts, while the rest keeps working
  • Unlock challenges that take real effort: QR or barcode, NFC tag, adaptive math, typing, stated intent, or waiting
  • An app with no internet permission, no accounts and no ads
  • Open source code under GPL v3 that anyone can read and build
  • No subscription, with no features held back for a paid tier

What you may lose

  • An iPhone app. Curbox is Android plus a browser extension for now
  • Website blocking in every browser. On Android it works in a listed set of browsers; others can be blocked as apps
  • Built-in location rules. These come from a separate location blocker add-on
  • In the Playstore variant, the UI Hider and anti-uninstall protection. Both are in the F-Droid and GitHub builds
