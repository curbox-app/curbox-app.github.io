Leaving AppBlock? Move in six stages.

AppBlock is one of the best known blockers, and its free plan is a good way to start. The free plan has caps, though, and once you hit them the next step is a subscription. This page is a migration checklist for moving your AppBlock setup to Curbox on Android, including the parts that do not carry over.

The migration checklist

Tick the boxes as you go. Nothing is saved, so keep this tab open while you work.

5 min

Write down what you have in AppBlock

There is no importer between the two apps. Before you change anything, open each AppBlock schedule and note it down.

5 min

Install Curbox and grant permissions

Get it from the official downloads page. Setup asks for three core permissions.

5 min

Turn Quick Block lists into Focus Groups

AppBlock's Quick Block is "block this list now." In Curbox that is Focus Mode, and each saved list is a Focus Group.

10 min

Rebuild your schedules

AppBlock bundles conditions into one schedule. Curbox splits them into groups that you can stack on the same app.

Choose how strict each group is

AppBlock gives you Strict Mode and a cooldown. Curbox sets strictness per group on the warning screen, so a bedtime block can be absolute while a social cap is merely annoying.

What does not carry over

Location and Wi-Fi conditions. Curbox has no built-in location or Wi-Fi rules. The open-source location blocker add-on uses the Curbox API to add location-based unlocks. There is nothing for Wi-Fi.

iPhone and Edge. AppBlock runs on Android and iOS and has extensions for Chrome, Edge and Brave. Curbox is Android only, with an extension on the Chrome Web Store and Firefox Add-ons.

In-app purchase and adult content blocking. Curbox has no switch for either. For adult sites you can import a keyword list into a Keywords And Websites group; the community Discord shares lists.

Backups that restore anytime. A Curbox backup can only be restored during setup, before onboarding ends, and you turn uninstall protection back on afterwards.

When AppBlock is the better pick

If your phone is an iPhone, or you need the same blocks on iOS and Android, AppBlock covers both and Curbox does not. The same goes if your schedules depend on where you are or which Wi-Fi you are on, or if you want an approval flow where another person signs off on unlocks. AppBlock is also built by a company, MobileSoft. Curbox is a community project with a Discord and GitHub issues.

Curbox is the better fit if you are on Android, you keep hitting free-plan caps, and you want things AppBlock does not list: blocking only Reels and Shorts inside Instagram, YouTube and Facebook, a live Reels counter, adaptive math and NFC unlocks, Urge Surfing, batched notifications and per-app grayscale.

Questions

Is Curbox a free alternative to AppBlock Premium?

Yes. Curbox is free and open source under the GPL v3 with no premium tier. There is no cap on groups, blocked apps, websites or keywords, and allowlists, backups and blocking newly installed apps cost nothing.

Does Curbox have something like AppBlock Strict Mode?

Set a group's warning screen to Never Unlock and the pause screen has no way past. In the F-Droid and GitHub builds you can also turn on anti-uninstall, which uses device administrator access. The Playstore build does not include anti-uninstall.

Can Curbox block apps by location or Wi-Fi like AppBlock?

Not built in. A separate open-source add-on, the Curbox location blocker, adds location-based unlocks through the Curbox API. There is no Wi-Fi condition.

Does Curbox work on iPhone, Windows or Mac?

Curbox is an Android app plus a browser extension on the Chrome Web Store and Firefox Add-ons. There is no iPhone app. AppBlock covers Android, iOS and Chrome, Edge and Brave extensions.

Can someone else approve my unlocks, like AppBlock third-party approval?

There is no approval request. You can get a similar effect by registering a QR code or NFC tag as the only way to unlock and giving it to someone you trust.

Can I import my AppBlock schedules into Curbox?

No. There is no importer, so you rebuild your schedules by hand. Stage 1 of the checklist on this page helps you write them down first so nothing gets lost.

Does Curbox need an account?

No. The Android app has no accounts and no internet permission. Sync for the browser extension is optional, off by default, and pairs directly with your own phone.
