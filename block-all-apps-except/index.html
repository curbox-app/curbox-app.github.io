Block all apps except the ones you need.

Sometimes a list of apps to block is the wrong way round. You want to block all apps except a few: your phone, your messages, maybe maps and music. Curbox's allowlist mode does exactly that on Android, for as long as a focus session runs.

Blocklist or allowlist: which one you need

Most app blockers start from a blocklist. You name Instagram, TikTok and YouTube, and those get blocked. That works until the urge moves somewhere you did not list: a news app, a game, a shopping app, the browser. Each new escape route needs another entry.

An allowlist (sometimes called whitelist mode) flips the question. Instead of "what should I block?" you answer "what do I actually need right now?". Everything else is blocked, including apps you install next week.

What usually belongs on the list. Your phone and messaging apps, so people can reach you. Maps if you travel during the session. A music or podcast app if it helps you work. Your authenticator app, because being locked out of a two-factor code at the wrong moment is a real problem. A calendar or notes app if your work lives there.

What usually does not. The browser, unless the work happens in it. Email, unless you are on call for it. Anything you would describe as "just checking".

How to set up allowlist mode in Curbox

Allowlist mode lives in Focus Mode, which runs timed sessions. Your list is saved as a Focus Group, so you build it once and reuse it.

Create the group

Open the Focus tab and tap Create Focus Group. Give it a name you will recognise, such as "Deep work" or "Exam".

Select the apps to keep

Tap Select Apps and choose your allowlist. Optionally tap Add Websites to include sites as addresses or keywords.

Choose the block mode

Pick Block All Except Selected. This is the setting that turns your list into an allowlist.

Decide how strict it is

Let me quit mid-sessions allows ending early. Turn on do not disturb silences notifications for the session. Pomodoro timer repeats the session in rounds with short breaks.

Save and start

Tap Save Group. Set the length with the slider, choose the group from the dropdown, and confirm. A 25-minute first session is a good test.

Run that first session as a test. Open each app you rely on and check it behaves as you expect, then lengthen the sessions. The Focus Mode docs cover every option, and Focus Stats tracks sessions, total focus time, completion rate and your day streak.

Can Android whitelist apps on its own?

Not quite. Android has tools that sit near this idea, and each is worth knowing, but none of them is an allowlist you control for yourself.

Digital Wellbeing Focus mode

A blocklist

You pick distracting apps to pause; everything else stays open. Apps you install later are not covered until you add them.

App pinning

One app only

Locks the screen to a single app until you unpin it. Useful for handing your phone to someone, too narrow for a work session that needs messages and music.

Bedtime mode

A mood, not a block

Grayscale and do not disturb at night. It changes how the phone feels but leaves every app open.

Menu names differ by phone maker. If you would rather block a few named apps on a schedule, App Pause is the better tool; see how to block Instagram on Android for that approach.

Questions

How do I block all apps except a few on Android?

Android does not have a built-in allowlist mode for your own use. In Curbox, create a Focus Group, select the apps you want to keep, choose the block mode Block All Except Selected, and start a Focus session. Everything you did not select is blocked until the timer ends.

Can I whitelist apps in Digital Wellbeing?

Digital Wellbeing's Focus mode works the other way round: you pick the distracting apps to pause, and everything else stays available. That is a blocklist. New apps you install are not covered until you add them. An allowlist blocks anything you did not choose, including apps you install later.

Will calls and alarms still work in allowlist mode?

Keep your phone app, messaging app and anything you rely on for emergencies in the selected list. Calls and alarms are system functions, but the safest habit is to run a short test session and check that everything you need opens.

Can I end an allowlist session early?

Only if you allow it. Each Focus Group has a Let me quit mid-sessions option. Leave it off for a session you cannot back out of, or turn it on while you are still finding the right list. A session marked as not quittable also cannot be ended early with an NFC tag.

Can I allow specific websites as well as apps?

Yes. A Focus Group can include websites as well as apps, entered as addresses or keywords, and the block mode applies to the group as a whole. Website matching works in Curbox's supported browsers, such as Chrome, Brave and Firefox.
