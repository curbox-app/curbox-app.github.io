Feature · Location add-on

Block apps based on location.

Some apps are fine at home and a disaster at the library. Curbox can act as a location-based app blocker on Android through a small open source add-on: a blocked app only unlocks when you are at a place you saved, or only when you are away from it.

Only here

Unlocks pass only inside the circle. Example: Instagram can be unlocked at home and nowhere else.

Anywhere but here

Unlocks pass everywhere except inside the circle. Example: no YouTube unlocks at the office or library.

How location-based blocking works in Curbox

Curbox itself does not use your location. The Android app has no location permission. Location support comes from a separate open source app, Location Blocker, which plugs into Curbox through the Curbox API.

The split of jobs is clean. Curbox does the blocking, shows the pause screen, and decides how long an unlock lasts. Location Blocker answers one question when asked: "Is this phone at the saved place right now?" Each saved place becomes an unlock requirement you can pick on a blocked group's pause screen, next to options like scanning a QR code or typing a sentence.

Location Blocker's README calls this "an unlock-time check, not continuous geofencing". Nothing watches you in the background. Here is roughly what happens when you tap to unlock a group set to "At Home":

00.0s Curbox pause screen: requirement "At Home"
00.1s Location Blocker opens its check
00.2s listening: GPS, network, fused (Android 12+)
01.8s fix ±140 m too vague
03.4s fix ±9 m, 22 m from centre inside area → PASS
03.4s Curbox unlocks for your configured duration

The timings are illustrative. The rules behind them are from the README: only live fixes count, it approves on the first passing fix, otherwise it listens for up to 20 seconds and judges the most precise one. Fixes older than 30 seconds, a denied permission, location turned off, or no fix at all mean no unlock.

Requirements can be used by app blocker groups, and the Curbox API documents the same warning option for keyword and reel blockers. Several places can be saved and assigned to different groups; each group selects one requirement.

Set it up

  1. Install Curbox and build Location Blocker from its source. It needs Curbox API version 3 or newer.
  2. In Location Blocker, under "Finish setting up", tap Connect and approve it in Curbox. Allow precise location and turn location on.
  3. Tap Add a place. Choose Only here or Anywhere but here. Stand at the spot and tap Use where I am now, or type coordinates. Pick the area size and, if you like, days and times.
  4. In Curbox, open the group you want to protect, then Warning Screen Configuration → Require effort to unlock → Require another app, and pick At [place] or Away from [place].
  5. Save, turn the group on, and make sure Curbox's App Blocker accessibility service is enabled.
  6. Keep Location Blocker itself out of your blocked apps. Use its Test here button, then try the real pause screen.

Saved places cannot be edited. To move a place or change its size, add a replacement and select it again in Curbox. That stops a requirement you picked from quietly changing meaning.

Privacy and honest limits

  • Minimal permissions. No account, no network permission, no background location, no foreground service, no location history. Coordinates stay in the add-on's private storage, with Android backup disabled.
  • Accuracy is an estimate. The place's centre is averaged from several live fixes, and the required precision scales with the area size. Small areas indoors may take longer to pass.
  • Not continuous. Leaving a place does not cancel an unlock you already have. Use On Each Open or short unlock durations for more frequent checks.
  • Not tamper-proof. Mock locations are rejected by default, but rooted phones and some spoofing methods are out of scope. Changing the phone's clock affects day and time schedules.
  • Trust. An approved API app can use the full Curbox API, not only location checks. Location Blocker's README says it only uses requirement registration, removal and listing, and its code is public to confirm that.

Sources: Location Blocker README and the Curbox API guide, checked November 2026.

Location blocker FAQ

Can I block apps based on location on Android?

Yes. With Curbox plus its free Location Blocker add-on, a blocked app can only be unlocked when you are at a saved place ("Only here") or only when you are away from it ("Anywhere but here"). The location is checked at the moment you try to unlock.

Does the location blocker track me in the background?

No. According to its README, Location Blocker uses no background location, no foreground service, no network permission, no account and no location history. It checks your position only when Curbox asks during an unlock, and saved places stay in its private storage with Android backup disabled.

What happens if I leave the place after unlocking?

The unlock you already got keeps running until it expires. The check happens at unlock time, not continuously. If you want frequent re-checks, use Curbox's On Each Open mode or a short unlock duration.

Can someone fake their location to get past it?

Mock locations are rejected by default, but the README is clear that it does not defend against rooted devices or every kind of location spoofing. Android location is an estimate, not proof of where you are.

Which permissions does it need?

Precise location with location services turned on. Approximate-only permission is not enough and denies access. Curbox itself does not need any location permission; that belongs to the add-on.

Where do I get the Location Blocker app?

It is open source on GitHub at github.com/curbox-app/location-blocker. When this page was written the repository had no published releases, so you build it from source. It needs a Curbox build with API version 3 or newer.
