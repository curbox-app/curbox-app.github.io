Feature · UI Hider · Instagram

Hide the Instagram feed. Keep your friends.

If you want to hide the Instagram feed on Android but still message people and see what your friends post, you need more than a time limit. Curbox can hide the suggested home feed and the Explore tab, leaving a Following-only feed, your DMs and Stories.

What changes when you hide the Instagram feed

Instagram opens on a home feed that mixes people you follow with suggested posts and Reels from accounts you have never heard of. It has a Following view, but you have to go looking for it each time, and the app does not remember the choice. Explore sits one tap away with more of the same.

Curbox's UI Hider covers those parts of the screen while the rest of Instagram keeps working. Here is the result, tab by tab.

Home feed Hidden Suggested posts and the mixed feed are covered.
Following Kept Tap the cursive "Instagram" text at the top to reach it.
Explore Hidden A separate rule, so you can keep Explore if you want it.
Reels Limit it Handled by the Reels limit, not the UI Hider. See below.
DMs and Stories Kept Messaging friends works as before.

Turn on the Instagram Following-only feed

You do not need to write anything. Curbox ships two Instagram rules that you switch on independently: hide the home feed except the Following tab, and hide the Explore tab.

Setup · about two minutes
  1. Install Curbox from the downloads page and finish onboarding, which grants the accessibility permission the UI Hider uses.
  2. Open Reducers → UI Hider and turn on Enable UI Hider.
  3. Toggle on the Instagram home feed rule, the Explore rule, or both.
  4. Open Instagram. To see posts from people you follow, tap the cursive Instagram text at the top and pick Following.

Two honest caveats. The UI Hider is part of the F-Droid variant of Curbox; the Playstore variant does not include it. And it is marked experimental: rules find parts of Instagram's screen by their ids, so an Instagram update can stop a rule matching until it is updated. The UI Hider docs track the details.

How hiding the feed works, line by line

The built-in rules are scripts written in a small language you can read and write yourself. The Curbox docs include a simple example that hides Instagram's home feed. It is short enough to walk through completely, and it shows how every UI Hider rule works: find two landmarks on screen, then cover what sits between them.

1
if app != "com.instagram.android" { return }

If the app on screen is not Instagram, stop. Scripts are tied to one app anyway, but returning early keeps every run cheap.

2
top = find(id="com.instagram.android:id/action_bar_container")

Find the bar at the top of the screen by its view id. find() returns the first matching node, or null if there is none.

3
nav = find(id="com.instagram.android:id/tab_bar")

Find the tab bar at the bottom. These two bars are the landmarks. Ids like these can change between Instagram versions.

4
if top != null and nav != null {

Only continue if both landmarks are on screen. Skipping this check is the most common reason a script misbehaves.

5
y = top.bottom

The covered area starts where the top bar ends. Every node exposes its geometry: top, bottom, left, right, width and height.

6
height = nav.top - y

It ends where the tab bar begins. The difference is how tall the feed area is.

7
if height > 0 { draw(0, y, screen.width, height) }

Draw an overlay across the full width of the screen over the feed. Overlays are redrawn on every run and clear themselves when you leave the app, so you never have to remove them.

8
}

Done. Because the script re-runs when you scroll or navigate, the overlay follows the live screen.

This documented example is deliberately simple: it covers whatever sits between the two bars whenever both are visible. The built-in rule goes further and leaves the Following tab reachable. If you adapt the example, a natural next step is to check which tab is selected before drawing, using selectors such as selected=true.

Show the whole script 
if app != "com.instagram.android" { return }
top = find(id="com.instagram.android:id/action_bar_container")
nav = find(id="com.instagram.android:id/tab_bar")
if top != null and nav != null {
    y = top.bottom
    height = nav.top - y
    if height > 0 { draw(0, y, screen.width, height) }
}

To add your own: Reducers → UI Hider → turn on the master switch → Add script → enter com.instagram.android → paste → Save. Scripts run sandboxed with limits on time and work, so a mistake is stopped instead of freezing the phone.

Hiding the feed is half the job

The feed is one way in. Reels are the other, and they reach you through DMs as well as their own tab. These pairings close the gaps.

Feed hidden + Reels capped

Use the Short-Form Video reducer to stop Reels after, say, 15 videos a day. You can still allow Reels opened from DMs. Read how to block Instagram Reels.

Feed hidden + a counter

The Reels counter shows a live number on screen as you scroll, which makes "just one more" harder to believe.

Feed hidden + evenings only

An App Pause group with a Time Based window allows Instagram only when you choose. See blocking Instagram on Android.

Questions people ask

Can I make Instagram show only posts from people I follow?

Instagram has a Following view, reached by tapping the Instagram logo text at the top of the home screen, but the app opens on the suggested home feed every time. Curbox's built-in Instagram rule hides the home feed except the Following tab, so the feed you land in is only accounts you chose.

Can you hide the Explore page on Instagram?

Not from Instagram's own settings. Curbox ships a separate built-in rule that hides the Explore tab, and you can turn it on with or without the home feed rule.

Will I still be able to send messages and see Stories?

Yes. The rules hide specific parts of the screen. Direct messages keep working, and you can still reach Following from the cursive Instagram text at the top.

Does hiding the feed also block Reels?

Not by itself. Reels have their own tab and show up in DMs. To limit them, use Curbox's Short-Form Video reducer, which stops Reels after a set number of videos or minutes a day. See the guide to blocking Instagram Reels.

Is the UI Hider available in every version of Curbox?

The UI Hider is part of the F-Droid variant of Curbox. The Playstore variant does not include it. Both variants include Reels limits, app time limits and unlock challenges. Official downloads are on the downloads page.
