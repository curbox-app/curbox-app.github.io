Hide YouTube recommendations on Android.

You open YouTube to look up one tutorial, and the home feed has other plans. Curbox can hide YouTube recommendations and remove the YouTube home feed on Android, so search, your subscriptions and the video you came for keep working while the rabbit hole disappears.

Why the YouTube home feed is the problem

Most people do not have a YouTube problem. They have a recommendations problem. Search is useful. A channel you follow for cooking or guitar lessons is useful. What eats the evening is the grid of suggested videos on the home screen and the column of "up next" picks beside every video, each one tuned to be the thing you click next.

YouTube itself does not give you a switch to turn that off. You can pause or clear your watch history, which can leave the home feed mostly empty, and you can mark single videos as "not interested". Neither removes the recommendations next to the video you are watching, and both are one tap away from being undone. Deleting the app works, but then you lose the useful part too.

Curbox takes a different route. Its UI Hider covers specific parts of an app's screen while the rest stays usable. Here is what that looks like on YouTube.

How to remove the YouTube home feed with Curbox

Setup takes a couple of minutes once Curbox is installed and its accessibility permission is granted.

  1. Install Curbox from the downloads page and finish onboarding.
  2. Open Reducers and tap UI Hider.
  3. Turn on Enable UI Hider.
  4. Toggle on one or both YouTube rules.
  5. Open YouTube. The hidden parts are covered as soon as they appear on screen.

Which version has it? The UI Hider is part of the F-Droid variant of Curbox. The Playstore variant does not include it. It is also marked experimental: rules find parts of YouTube's screen by their ids and labels, and when YouTube changes those in an update a rule can stop matching for a while. Full details are in the UI Hider docs.

Write your own rule

The built-in rules are written in a small scripting language that you can use too. A script is tied to one app package, runs only while that app is on screen, and re-runs when the screen changes. Every run is sandboxed with strict limits on time and work, so a broken script is stopped instead of freezing your phone.

Below is an illustrative example that hides the main scrolling list while the Home tab is selected. It uses the documented functions, but YouTube's labels and ids differ between versions and languages, so treat it as a starting point to adapt, not a tested rule.

if app != "com.google.android.youtube" { return }

home = find(desc="Home", selected=true)
if home == null { return }

feed = find(scrollable=true)
if feed != null {
    hide(feed)
}
  1. Check the app. Stop straight away if YouTube is not in the foreground. Cheap early returns keep scripts fast.
  2. Find the Home tab. find() returns the first node matching every selector, here a node described as "Home" that is currently selected.
  3. Only act on Home. If the Home tab is not selected, return. Search and Subscriptions are left alone.
  4. Find the feed. The first scrollable node on the Home screen is usually the recommendation list.
  5. Hide it. Always null-check before using a node. The overlay is redrawn on every run and clears itself when you leave the app.

To add it: Reducers → UI Hider → turn on the master switch → Add script → enter com.google.android.youtube as the package → paste the script → Save. Syntax errors are reported when you save. If you need a localized label, appString("resource_name") resolves the app's own string.

YouTube in a browser, and on a computer

In a browser on Android. The UI Hider works inside apps, not web pages. What Curbox can do in supported browsers (Chrome, Brave, Firefox, Opera and several others) is block parts of a site by address. youtube.com/shorts blocks only Shorts and leaves normal videos alone. There is no documented keyword for "only the home page", so if the website's home feed is your weak spot, the YouTube app with the UI Hider is the stronger setup. The website blocking guide covers the keyword syntax.

On a computer. The Curbox browser extension for Chrome, Brave and Firefox tracks the time you spend on sites, blocks them by schedule or usage, and filters feeds such as Shorts with keyword and pattern matching while the rest of the site stays usable.

Pair it with a limit

Hiding the feed removes the trigger. A limit catches the habit if it finds another way in. Two combinations work well:

  • Hide the feed and cap Shorts. Use the Short-Form Video reducer to stop Shorts after a number of videos or minutes. See how to block YouTube Shorts.
  • Hide the feed and add a daily allowance. An App Pause group with a Usage Based limit (say 45 minutes) blocks YouTube once you have had your time, with whatever unlock challenge you choose.

Questions

Can you turn off YouTube recommendations in the YouTube app?

Not fully. YouTube lets you pause or clear your watch history, which can leave the home feed mostly empty, and you can tell it you are not interested in individual videos. There is no switch that removes recommendations from the home screen and the side of the player. Hiding them on Android takes an outside tool that can draw over the app, like Curbox's UI Hider.

Will hiding the YouTube home feed break search or subscriptions?

No. The "hide the feed so only search results are visible" rule covers the recommendation feed and leaves the search bar working. With "hide everything except the video", recommendations, comments and the description are removed from the watch screen, and the video itself plays as normal.

Is the UI Hider in the Google Play version of Curbox?

No. The UI Hider is part of the F-Droid variant of Curbox. The Playstore variant does not include it. Both variants can still limit YouTube Shorts and set time limits on the YouTube app. Every official download is listed on the downloads page.

Does this work on YouTube in a browser?

The UI Hider works inside Android apps. In a supported browser on Android you can use Curbox's keyword blocker to block sections such as youtube.com/shorts, but there is no documented keyword for only the home feed. On a computer, the Curbox browser extension filters feeds such as Shorts with keyword and pattern matching.

Why did the hidden feed come back after a YouTube update?

UI Hider rules find parts of the screen by their view ids and labels. When YouTube changes those in an update, a rule can stop matching until it is updated. The feature is marked experimental for this reason. If you write your own script, re-check the ids after an update.
